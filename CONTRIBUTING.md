# Contributing to LSTM2RL-SynthCryptoMarketMaker

Thank you for your interest in contributing to **LSTM2RL-SynthCryptoMarketMaker**! Contributions of all kinds are welcome, including bug fixes, feature implementations, and documentation improvements. This guide outlines the process to ensure a smooth and efficient contribution experience.

## How to Contribute

### 1. Fork the Repository
- Click the **"Fork"** button in the top-right corner of the repository page to create your personal copy of the project.

### 2. Clone Your Fork
- Clone the repository to your local machine:
  ```bash
  git clone https://github.com/<your-username>/LSTM2RL-SynthCryptoMarketMaker.git
  cd LSTM2RL-SynthCryptoMarketMaker
  ```

### 3. Set Up Your Environment
- Install the dependencies using [Poetry](https://python-poetry.org/):
  ```bash
  poetry install
  ```

### 4. Choose an Issue
- Browse open [issues](https://github.com/luca-nik/LSTM2RL-SynthCryptoMarketMaker/issues) or create a new one if none match your ideas.
- Comment on the issue you'd like to work on to avoid duplicate efforts.

### 5. Create a Branch
- Work on your contributions in a separate branch:
  ```bash
  git checkout -b feature/your-feature-name
  ```

### 6. Make Changes
- Follow the project's coding standards and guidelines while making changes.
- Regularly commit your progress:
  ```bash
  git commit -m "Brief description of your changes"
  ```

### 7. Test Your Changes
- Ensure your changes are thoroughly tested. Include new test cases if applicable.

### 8. Submit a Pull Request (PR)
1. Push your branch to your forked repository:
   ```bash
   git push origin feature/your-feature-name
   ```
2. Navigate to the original repository and click **"New Pull Request"**.
3. Provide a detailed description of the changes, linking any related issues.

---

## Style Guide

- **Commit Messages**: Use clear, concise language describing your changes.
- **Code Formatting**: Follow Python's [PEP 8](https://peps.python.org/pep-0008/) guidelines.
- **Documentation**: Update relevant documentation in `README.md` or inline comments.

## Reporting Issues

- Clearly describe the problem, steps to reproduce it, and expected vs. actual behavior.
- Include any relevant error messages, logs, or screenshots.

Thank you for your contributions! 🎉
